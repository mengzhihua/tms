# TMS 技术方案

TMS 负责运输订单、调度运单、在途轨迹和运费账单。IR 把运单和账单拉成快照，并下发调度、追轨迹、换承运商。

## 1. 运行位置

| 场景 | 后端 | 说明 |
| --- | --- | --- |
| 单机 | `8080` | `application.yml` |
| 发行包 | `8082` | `scripts/package-native.sh`，与 IR `data.sql` 的 `base_url` 一致 |
| 源码直接启动 | `8080` | `application.yml`。同机联调发行包时用 `8082` |

控制塔种子把 TMS 配成 API Key，键 `tms-open-key`。Open IR 写接口校验 `X-Api-Key`。

## 2. 主链路

```text
运输订单 → 调度运单 → 发车 → 在途/围栏 → 到达 → 签收
三方物流适配器同步轨迹；计费按重量、体积、件数或里程出账单
```

## 3. 控制塔读

`GET /api/open/ir/snapshots`：

| 块 | 内容 |
| --- | --- |
| `waybills` | 运单号、来源单号、承运商、状态、计划/实际到达、运费、异常 |
| `bills` | 运费账单金额 |

没有 Key 时，控制塔改拉 `/api/waybill/page`、`/api/billing/page`、`/api/dashboard`。

## 4. 控制塔写

写指令始终打 Open IR，不走登录后的运单口。统一口不可用时回退专用口。

| 指令 | 专用口 | 作用 |
| --- | --- | --- |
| `TMS_DISPATCH` | `POST /api/open/ir/dispatch` | 按运单号调度，可带承运商 |
| `TMS_SYNC_TRACK` | `/sync-track` | 同步轨迹 |
| `TMS_SWITCH_CARRIER` | `/switch-carrier` | 按运单号换承运商 |

业务键是运单号。非空 `idempotencyKey` 按 `type|运单号|key` 去重。

OMS 发货后调用 `POST /api/open/transport-order`，同样校验 `X-Api-Key`。来源单号重复推送返回已有运输订单。正常签收后，`tms.oms.mode=http` 时把来源单号回写 OMS `POST /api/open/tms/signed`。异常签收不推。默认 mock，不外呼。

调度台 `GET /api/dispatch/recommend?preference=FAST|CHEAP|BALANCE|SCORE` 在顺丰、京东、自有车队中择优。时效优先选顺丰（1 天，费率 2.2），成本优先选自有车队（3 天，费率 1.4），平衡只在 2 天内可达的承运商里选费率更低的京东（2 天，费率 1.8）。`SCORE` 用已送达或已关闭运单记分：准时 50、无异常 30、费用贴合 20。费用偏差拿实付对比原运费账单，换商差额单不算进原报价。没有完成运单时改用平衡。费率与换商折算共用 `CarrierRates`。

已送达的正向订单可 `POST /api/order/{id}/return` 另开一张 `RETURN` 回货单，收发双方对调，来源单号是原运输订单号。重复调用返回同一张回货单。回货单签收不回写 OMS。

调度台在选定线路和车辆后显示报价说明，写明距离和车型。运单调度落账时，账单说明同样带上距离、车型和车牌。

三方取号默认仍由本地适配器生成。`tms.express.mode=http` 时改为 `POST {base}/api/open/waybill`，响应 `data.trackingNo` 作为面单号。承运商填了取号地址时走该地址，否则用全局地址。两边都空或返回码不是 0 时取号失败。默认 mock，不外呼。

调度台 `GET /api/dispatch/map-bind` 按收货坐标把待派订单绑到最近且装得下的空闲车。没有收货坐标时用起点站。没有坐标或没有空位的订单不绑。绑车结果在调度台用地图底图标出订单和车辆，底图来自 OpenStreetMap。

调度落账时，原费率之外再加距离费和车型费：每公里 1 元；4.2 米 20 元，6.8 米 35 元，9.6 米 50 元。其他车型不加车型费。账单说明里同时写上这段公式。

## 5. 边界

换承运商改 TMS 运单，并另记一张 `FREIGHT_DELTA` 运费差额单（新运费减原运费）。控制塔上的节省额仍是估算。`tms.bms.mode=http` 时把这张差额单推到 BMS，金额按声明值入账；默认 mock，不外呼。
