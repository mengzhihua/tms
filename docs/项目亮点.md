# TMS 亮点

TMS 管运输订单、调度、在途和运费。自有运力和三方承运商走同一张运单。

1. **调度同时覆盖自有车辆和三方承运商。** 运单可以从发车走到到达、签收、关闭或取消。
2. **在途不是只记一个状态。** GPS、轨迹事件、圆形和多边形围栏都能产生进入和离开告警，也可以模拟行驶。
3. **三方轨迹能拉回来。** 顺丰、京东、中通的模拟适配器负责同步轨迹和回调签收，控制塔也可以按运单号触发同步或换承运商。
4. **运费在本系统算清。** 按重量、体积、件数或里程计费，支持首续单位和最低收费。账单能单独查，也能给控制塔做成本快照。
5. **控制塔写指令只打开放口。** 调度、同步轨迹、换承运商都带幂等键。没有登录账号时也不会改去打内部运单页，避免同一张运单被两套入口各改一次。
